## Demonstração ##
### Ao executar o programa, será solicitado duas notas ao usuário: ###

== SISTEMAS DE NOTAS ==

1. *Digite a primeira nota: 8*
2. *Digite a segunda nota: 7*
   
**A média final é: 7.50 Status: APROVADO!**

=======================================================================

## Regra Utlizada ##

- Média maior ou igual a 7.0 → APROVADO
- Média menor que 7.0 → REPROVADO
